# Учёба

Учебный помощник для Windows и Android: дедлайны, фото-калькулятор, решение по шагам, рефераты и слайды, ИИ-чат.

## Скачать
Готовые файлы — справа в разделе **Releases** (последняя версия):
- `Ucheba-Setup-*.exe` — установщик для Windows
- `Ucheba-Portable-*.exe` — Windows без установки
- `Ucheba-Android.apk` — Android

## Ключи
При первом запуске введите свои ключи:
- OpenRouter — https://openrouter.ai/keys (основной ИИ, есть бесплатные модели)
- Google Gemini — https://aistudio.google.com/apikey (запасной ИИ)
- PDF.co — https://app.pdf.co (необязательно)

Ключи, дедлайны и история хранятся только на устройстве пользователя.
